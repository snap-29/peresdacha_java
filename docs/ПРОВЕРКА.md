## Ограничения проверки

Docker Engine / CLI отсутствует в среде. Образ и Compose здесь не запускались;
фактическая работа с PostgreSQL и сохранение Docker volume требуют выполнения
команд из README на компьютере с Docker. Структура YAML проверена, оба healthcheck
заданы; совместимый SQL выполнен на H2. Проверку на PostgreSQL не выдаём за выполненную.
Исторический исходный Spring Core проект не предоставлен, поэтому неизменность
старого файла контроллера после смены репозитория проверить нельзя.
